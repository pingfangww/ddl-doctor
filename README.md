# 🏥 急稿问诊室 — DDL Doctor

> 你的论文是"患者"，Agent 是"医生"。挂号、问诊、开处方、手术、出院——把赶 DDL 这件事从头到尾办完。

**[👉 在线体验](https://pingfangww.github.io/ddl-doctor/)**

## 这是什么

「急稿问诊室」是一个学习搭子 Agent 的交互原型，用医院问诊的隐喻重新设计了"赶 DDL 写论文"的完整流程。

每个大学生都知道赶 DDL 跟看急诊没区别——焦虑→被接住→一步步推进→完成的解脱。这个产品把这种感受变成了产品语言。

## 核心设计

### 八步诊疗流程 × Agent 编排

| 问诊流程 | Agent 模块 | 编排逻辑 |
|---------|-----------|---------|
| 🏥 挂号 | 意图识别 + 信息提取 | 解析用户输入 → 提取课程/字数/DDL |
| 🩺 问诊 | 智能追问（Clarify） | 信息完备度 < 阈值时触发，> 阈值则跳过 |
| 🏷️ 分诊 | DDL 分级 + 节奏调整 | 根据时间紧迫度动态切换交互风格 |
| 📋 开处方 | 选题推荐 + 大纲生成 | 等待用户确认后才进入下一步（人工门控） |
| 🔪 手术 | 带上下文的分段写作 | 维护"病历"工作记忆，自动衔接前文 |
| 💉 化验 | 引用查证 + 诚实标注 | 不确定项标 ⚠️，绝不静默放行 |
| 🩹 包扎 | 格式排版 + 文件生成 | 一键输出可提交的 Word |
| ✅ 出院 | 质量门控 + 出院证明 | 检查清单全部通过后才放行 |

### 分诊等级——自适应交互节奏

| 等级 | 条件 | Agent 风格 |
|------|------|-----------|
| 🟢 门诊 | 距 DDL > 3 天 | 从容引导，充分讨论选题 |
| 🟡 急诊 | 距 DDL 1-3 天 | 明确节奏，直接出大纲拍板 |
| 🔴 抢救 | 距 DDL < 24 小时 | 直接上手，你负责确认 |
| 💀 ICU | 已逾期 | 最小可交付版本优先 |

### 三个设计原则

1. **医生主动推进，患者随时拍板** — 做完一步自动推下一步，但关键节点设有人工门控
2. **病历持久化，中断可恢复** — Agent 维护任务级工作记忆，关掉页面再回来，读病历就知道做到哪了
3. **诚实标注不确定性** — 宁可标 ⚠️ 让用户核实，也不编造引用

## Demo 说明

单文件 HTML（130KB），内置 **4 个场景 × 3 个选题方向 = 12 条独立对话路径**：

- 📝 古代晚期课程论文（🔴 抢救）— 衰落叙事 / 基督教转型 / 气候与瘟疫
- 📖 现当代文学读书报告（🟡 急诊）— 余华《活着》/ 张爱玲《金锁记》/ 鲁迅《野草》
- 🔬 公共卫生导论期末论文（🟢 门诊）— 传染病预警 / 疫苗犹豫 / 环境健康
- 💻 AI伦理课程论文（🟡 急诊）— 算法偏见 / AI版权 / 自动驾驶伦理

每条路径有独立的大纲、写作内容、引用化验和出院评语。

### 视觉风格

手绘笔记本风格：Rough.js 涂鸦、Caveat 手写字体、格线纸背景、微微歪斜的卡片。不是冰冷的医院，更像校医院 + 学生的自嘲式幽默。

### 技术栈

- 纯前端单文件，零构建依赖
- [Rough.js](https://roughjs.com/) — 手绘风格 SVG
- [Lottie](https://airbnb.io/lottie/) — 打字动画
- [Caveat](https://fonts.google.com/specimen/Caveat) — 手写字体
- Blob API — 文件下载
